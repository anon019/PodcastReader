# Asset provenance

`Assets/AppIcon-master-v2.png` was generated specifically for Podcast Reader on 2026-08-05 using OpenAI image generation, then locally processed to remove the chroma-key background and preserve transparency. `Assets/AppIcon.icns` is the macOS icon set derived from that master image.

The repository owner releases these two original project assets under the same MIT license as the source code. Podcast names, channel names, episode thumbnails, and third-party logos displayed at runtime are not repository assets and are not covered by that license.
